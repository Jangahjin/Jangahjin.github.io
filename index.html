About

보여주는 데서 멈추던 작업을,
움직이게 만들고 싶었습니다. My work used to stop at showing.
I wanted to make it move.

시각디자인을 공부하는 동안 제 작업은 늘 보여주는 데서 멈췄습니다. 포스터는 출력하면 끝이었고, 웹 화면은 디자인해도 직접 눌러 볼 수 없었습니다.

While studying visual design, my work always stopped at being shown. A poster was finished once it was printed, and a web screen I designed was something I could never actually click.

그 아쉬움으로 졸업을 앞둔 겨울 웹개발 기초 강의를 들었고, 지금은 국비 과정에서 Java와 React를 배우며 팀 프로젝트에서 제가 디자인한 화면을 직접 구현하고 있습니다.

That frustration led me to a web development course the winter before graduation. Today I'm learning Java and React in a government-funded training program, implementing the screens I design in team projects.

새로운 기술은 Claude Code·ChatGPT 같은 AI 도구의 도움을 받아 익히되, 답을 그대로 쓰기보다 왜 그렇게 동작하는지 이해하고 넘어가려고 합니다.

I pick up new technology with help from AI tools like Claude Code and ChatGPT — but rather than pasting answers, I make sure I understand why the code works.
